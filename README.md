# charlestoriola.com — portfolio

Static, dependency-free portfolio for Charles Toriola (full stack developer and creative lead, Abuja).

Pages

- `/` (builds): cursor-swarm intro, hero with "click to use" pixel cursors, animated project cards
- `/studio` (was `/fun`, which redirects here): posters, brand systems, event films, live production and software on horizontal shelves
- `/work/<slug>`: case studies (3 brand overhauls, 6 software builds), linked from the studio page tiles and the home page cards
- `/art`: a desktop of draggable folders that open into windows with a lightbox
- `/about`: polaroids, journey, contact details and a live Abuja clock

Run locally

```bash
python3 -m http.server 8080
```

Deploy: push to Vercel (static, `vercel.json` enables clean URLs like `/studio`).

Structure

- `assets/css/style.css`: all styles
- `assets/js/common.js`: pixel-art icon renderer, bottom dock, pen/eraser tool state, clock
- `assets/js/draw.js`: pixel ink layers (draw, erase, save)
- `assets/js/stickers.js`: draggable sticker photos on About

When you change a CSS or JS file, bump the `?v=` number on its `<link>`/`<script>` tags so browsers fetch the new copy. Images are cached for an hour; to show a replaced image straight away, give the new file a new name.
- `assets/js/home.js`: intro animation, stacked project sheets, weighted scroll
- `assets/js/scenes.js`: animated project card scenes, shared by the home page and the software case studies
- `work/*.html`: case study pages, generated by `scripts/build_cases.py` (edit the `CASES` table there and rerun it rather than editing the HTML by hand)
- `assets/img/cases/`: case study screenshots and fun-page thumbnails
- `scripts/seo_meta.py`: who Charles is for search engines and AI tools (roles, Abuja, services, stack). `scripts/build_seo.py` writes titles, descriptions, canonical links and JSON-LD into the main pages and regenerates `sitemap.xml`, `robots.txt` and `llms.txt`. Run `python3 scripts/build_cases.py && python3 scripts/build_seo.py` after editing pages or adding a case study.
- `assets/js/art.js`: desktop folders, windows, lightbox
- `assets/img/`: portraits, posters, blue duotone hero cutout, stream frames (`live/`), event film stills (`events/`)
- `assets/video/`: 5-second muted event film loops (480px wide, H.264, no audio), played only while on screen
