01The original

I ran the PHP and MySQL setup behind Wepluz's school admin software, where staff manage students, classes and results. It's now used daily in 100+ schools, some with over 500 students, and it has to be right every morning, because a whole school opens it to start the day.

For most of the job I worked solo. Two contracted senior developers came in once in a while, sometimes only over the phone, so most of the day-to-day building, fixing and keeping it running was mine.

02The overhaul

The overhaul was the uphill part, and I did it on my own: a rebuild from scratch as Wepluz School Manager, a multi-school platform where each school only ever sees its own data:

  • A React web app (Vite, TypeScript, Tailwind) on Firebase Auth and Firestore, hosted on Vercel.
  • Reads come straight from Firestore, limited by security rules to the person's school and role. Every write goes through one server function that checks the school's rules, such as term dates inside the session and one teacher per subject per class, then records an audit log entry.
  • Parents sign in with a 6-digit code by SMS, so they don't need an email account.
  • 80 tests run against the Firebase emulators, covering the security rules and every server action.

03The design system

A mint backdrop, a white rounded app frame and soft grey cards, set in Outfit, with teal for the brand and sunflower for highlights. On desktop the menu is an icon rail that curves out of the frame's left edge; on phones it becomes a labelled drawer. The dashboard adapts by role: leadership sees school-wide numbers, teachers see their classes and registers, parents see their children. The charts are hand-built, with no chart library, and include a table for screen readers.

04Try the demo

The live demo runs a sample school with one-click sign-ins for every role: proprietor, principal, school admin, bursar, teachers and parents.

05What it taught me

Building for schools meant building for real users with real deadlines: result days, new terms, a full intake. It's where I learned that reliability is a feature, and it's the reason I still build end to end.
