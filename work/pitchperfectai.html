01The problem

Founders and teams usually have the material, a brief, a few documents, the code itself, but not the deck. Turning that into a pitch is days of work that has little to do with building the product.

02What it does

Give it a written brief, upload documents or point it at a GitHub repo. It returns a deck in the order investors expect:

  • The problem, the solution and the market size
  • Product, how it works and traction
  • Business model, competition and go-to-market
  • Team, financials and the ask

03How it's built

A Flask backend reads the inputs and has Gemini draft each slide. A deck builder then splits the content into slide-sized sections, the same approach I later reused in PDF → Slides.
