01The idea

Most file sharing asks you to trust the server with your files. NCrypt doesn't: contracts, payroll sheets and brand assets are encrypted on your own device first, so what gets uploaded is ciphertext.

02How it's built

A React front end on the browser's built-in Web Crypto API, using AES-GCM with 256-bit keys. No crypto libraries to ship or trust, and the plaintext never leaves the page.
